# My agent: financial-recovery-agent
One-liner: A conversational agent that helps financial scam victims navigate immediate incident triage, report fraud, stabilize their finances, and follow step-by-step recovery plans with a catalog of verified relief resources and agency directories.

Tool coverage:
- Memory: Incident details (scam type, date, amount, compromised accounts), recovery checklist progress, and user preferences
- Tools: Scam incident triage, relief agency directory lookups, and dispute letter template generation
- Catalog/UI: Action checklist cards, verified reporting agency directory cards, and disputed claim tracking tables
- Image gen: Personalized recovery roadmap and step-by-step milestone timeline infographics
- Sandbox: Emergency cash flow calculations and statutory dispute deadline date math

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): code sandbox for financial timeline and deadline math, external legal/relief APIs, Cloud Trace
